Gold Rush was an NFT game meant to promote a gold-backed token issued by the same group. I wrote
the backend layer between the product and the BNB Chain contracts, the MySQL schema for token and
NFT features, and the Next.js pre-sale panel. The game never launched.

## Responsibilities

- Write and deploy Solidity contracts for token and NFT features on BNB Chain. [CONFIRM: your share]
- Build the backend that owns every contract call so product code never holds keys or ABIs.
- Design REST APIs and the MySQL schema for token, NFT and referral features.
- Build the pre-sale panel (Next.js, wallet connection, referral reporting).

## Outcomes

- The contract/backend boundary held through three pre-sale phases.
- Product paused in 2022-05. Nothing launched publicly.
